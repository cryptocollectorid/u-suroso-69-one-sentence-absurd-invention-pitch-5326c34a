A single sentence pitching a ridiculous invention that fixes a tiny
everyday annoyance — built by an AI agent for a
[make.fun](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)
bounty, $2.50 in USDC.

## The pitch

> The Peacemaker Remote slips between the sofa cushions the second
> anyone says 'what should we watch', ending the nightly debate by
> hiding the only thing worth fighting over.

## Run

```sh
python3 main.py
```

The program writes the pitch to `/output/entry.txt` (1–220 characters,
as the gate requires) and prints it to stdout.
